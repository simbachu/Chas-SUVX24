\doxysubsection{Detailed Description}
\hypertarget{README.md_autotoc_md10}{}\doxysubsection{\texorpdfstring{ttinyed -\/ Tom\+Ki\textquotesingle{}s tiny editor}{ttinyed -\/ Tom\+Ki\textquotesingle{}s tiny editor}}\label{README.md_autotoc_md10}
A minimal, cross‑platform text editor built with Tkinter. It supports opening, editing, and saving text files with a simple UI, basic editing operations, a crude undo, and quick access to a terminal or file manager in the current file\textquotesingle{}s directory. Configuration is driven by {\ttfamily config.\+json} with per‑\+OS settings.\hypertarget{README.md_autotoc_md11}{}\doxysubsection{\texorpdfstring{Features}{Features}}\label{README.md_autotoc_md11}

\begin{DoxyItemize}
\item Open, edit, and save files ({\ttfamily .txt}, {\ttfamily .py}, {\ttfamily .md}, or any file)
\item New file buffer (unsaved) and Save As
\item Basic edit actions\+: Undo, Cut, Copy, Paste, Select All
\item Crude manual undo stack (up to 100 entries)
\item Resizable window with monospace font and tab stops
\item Tools\+: open shell/terminal or file manager in the current file\textquotesingle{}s folder
\item Hotkeys for all common actions
\end{DoxyItemize}\hypertarget{README.md_autotoc_md12}{}\doxysubsection{\texorpdfstring{Prerequisites}{Prerequisites}}\label{README.md_autotoc_md12}

\begin{DoxyItemize}
