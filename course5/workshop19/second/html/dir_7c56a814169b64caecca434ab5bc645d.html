Detailed Description

ttinyed - TomKi's tiny editor

A minimal, cross‑platform text editor built with Tkinter. It supports opening, editing, and saving text files with a simple UI, basic editing operations, a crude undo, and quick access to a terminal or file manager in the current file's directory. Configuration is driven by config.json with per‑OS settings.

Features

  • Open, edit, and save files (.txt, .py, .md, or any file)
  • New file buffer (unsaved) and Save As
  • Basic edit actions: Undo, Cut, Copy, Paste, Select All
  • Crude manual undo stack (up to 100 entries)
  • Resizable window with monospace font and tab stops
  • Tools: open shell/terminal or file manager in the current file's folder
  • Hotkeys for all common actions

Prerequisites

  • Python 3.7+ (Windows or Linux)
  • Tkinter installed (usually included with standard Python distributions)

Check Tkinter:

python -c "import tkinter; print('tk ok')"

If this fails, install Python with Tk support (e.g., sudo apt install python3-tk on Debian/Ubuntu).

Install

Clone the repository and enter the folder:

git clone https://github.com/TomasKindahl/ttinyed.git
cd ttinyed

No dependencies beyond the Python standard library are required.

Run

From the project directory (where ttinyed.py and config.json are located):

  • Linux:
    python3 ttinyed.py
  • Windows (PowerShell or CMD):
    python ttinyed.py

You can also open a file directly by passing its path:

python ttinyed.py /path/to/file.txt

On Windows, you can associate .txt/.md to run with python ttinyed.py "%1" if desired.

Usage

  • New file: File → New (or Ctrl+N)
  • Open file: File → Open (or Ctrl+O)
  • Save: File → Save (or Ctrl+S). For a new buffer, a Save dialog appears.
  • Save As: File → Save as (or Ctrl+Shift+S)
  • Exit: File → Exit (or Ctrl+Q)

When a buffer has unsaved changes, the window title is prefixed with *.

Editing

  • Undo: Edit → Undo (or Ctrl+Z)
  • Cut: Edit → Cut (or Ctrl+X)
  • Copy: Edit → Copy (or Ctrl+C)
  • Paste: Edit → Paste (or Ctrl+P)
  • Select All: Edit → Select All (or Ctrl+A)

Note: Paste (Ctrl+P) uses an internal buffer for copy/cut; it does not access the system clipboard.

Tools

  • Open Shell in current file directory: Tools → Shell (or Ctrl+Alt+S)
  • Open File Manager in current file directory: Tools → File manager (or Ctrl+Alt+F)

Configuration (config.json)

The app reads config.json in the working directory and selects settings based on your OS name (Windows or Linux). Example:

{
"Linux": {
"pathsepr": "/",
"pathemb": "'",
"shell": "xfce4-terminal --default-working-directory=",
"filemgr": "thunar",
"fontsize": 20
},
"Windows": {
"pathsepr": "\\",
"pathemb": "",
"shell": "start /wait cmd /k cd ",
"filemgr": "explorer",
"fontsize": 10
}
}
  • pathsepr: path separator for the platform (/ or \\).
  • pathemb: quote/escape wrapper for file manager paths (e.g., ‘"&rsquo;"` on Linux).
  • shell: command to open a terminal in a specific working directory. The editor will append the target path.
  • filemgr: file manager executable to open a folder.
  • fontsize: base UI font size.

Adjust shell and filemgr to match your environment, e.g., on GNOME: shell: "gnome-terminal --working-directory=", filemgr: "nautilus".

Keyboard Shortcuts

  • Ctrl+N: New
  • Ctrl+O: Open
  • Ctrl+S: Save
  • Ctrl+Shift+S: Save As
  • Ctrl+Q: Exit
  • Ctrl+Z: Undo
  • Ctrl+X: Cut
  • Ctrl+C: Copy
  • Ctrl+P: Paste (internal buffer)
  • Ctrl+A: Select All
  • Ctrl+Alt+S: Open Shell in file directory
  • Ctrl+Alt+F: Open File Manager in file directory

Notes and Limitations

  • Undo is a simple stack; redo is not implemented.
  • Paste uses an internal buffer, not the system clipboard.
  • When launched with a file path, the editor loads that file if it exists; otherwise, it treats the path as the current buffer name until saved.

Troubleshooting

  • Window too small/large: adjust fontsize in config.json.
  • Terminal or file manager does not open: update shell/filemgr in config.json to match your desktop (e.g., konsole, kitty, nautilus, dolphin, explorer).
  • Tkinter missing: install python3-tk on Linux (sudo apt install python3-tk). On Windows, use the official Python installer which includes Tk.
